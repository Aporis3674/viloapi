# viloapi

نصب‌کنندهٔ Xray و API محلی مدیریت سرور برای ViloShop. دامنه نیاز ندارد. ربات سرورلس فعلی به‌تنهایی SSH ندارد؛ اتصال مدیریتی فقط از یک عامل مجزا با SSH امن ممکن است. رابط وب مدیریتی وجود ندارد.

## پیش‌نیازها

- VPS خالی Ubuntu 22.04+ یا Debian 12+ با systemd؛ معماری amd64 یا arm64.
- دسترسی root و IPv4 عمومی؛ دامنه لازم نیست.
- ورودی TCP پورت‌های 80 و 443 باز؛ دسترسی خروجی به GitHub برای دریافت Xray و کد عامل.
- روی سرور فعلی دارای مشتری اجرا نکنید. نصب‌کننده از بازنویسی نصب شناخته‌شده جلوگیری می‌کند؛ مهاجرت نصب‌های دیگر خودکار نیست.

## نصب

یک دستور اجرا کنید؛ نصب‌کننده IPv4 عمومی را تشخیص می‌دهد، وابستگی‌ها و سرویس‌ها را نصب می‌کند و کلیدهای اتصال را تولید می‌کند. فایروال پنل میزبان خارج از دسترسی نصب‌کننده است. اسکریپت در پوشه موقت مستقل دانلود می‌شود و فقط پس از دانلود موفق اجرا می‌شود:

```bash
work=$(mktemp -d) && curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/Aporis3674/viloapi/main/scripts/install_node.sh -o "$work/install_node.sh" && bash "$work/install_node.sh"
```

کد دانلودشده با دسترسی root اجرا می‌شود؛ پیش از اجرای آن کد را بازبینی کنید. برای نصب تکرارپذیر، `main` در URL را با SHA کامیت مورد نظر جایگزین کنید و همان SHA را با `sudo env VILO_REF=<SHA> bash ...` به نصب‌کننده بدهید.

خروجی نصب IP و آدرس ساب است. برای ثبت و مدیریت سرور، عامل SSH جداگانه باید مشخصات IP، پورت SSH، نام کاربری و کلید PEM را **خارج از گروه عمومی** دریافت کند. کلید خصوصی یا فایل `/etc/vilo-node/node.json` را در چت عمومی نفرستید. ثبت مستقیم با توکن `vilo1.` در ربات سرورلس فعلی برای نصب بی‌دامنه پشتیبانی نمی‌شود.

## اجزا

- VLESS Reality روی 443؛ مسیر جایگزین مستقل WebSocket روی 80 (`/vilo-ws`). تغییر خودکار مسیر در کلاینت پیاده‌سازی نشده است.
- ساب با HTTP روی IP و پورت 80 ارائه می‌شود؛ URL شامل UUID است و HTTP روی شبکه رمزنگاری ندارد. اگر محرمانگی لینک ضروری است، HTTPS با دامنه یا گواهی معتبر IP لازم است.
- API مدیریت فقط روی loopback (`127.0.0.1:10086`) در دسترس است؛ هیچ کلید مدیریتی روی HTTP عمومی ارسال نمی‌شود.
- StatsService روی `127.0.0.1:10085`، ورودی WS داخلی روی `127.0.0.1:10087`.
- سرویس‌های `vilo-xray` و `vilo-node`؛ ذخیرهٔ مصرف در SQLite؛ بررسی حجم و انقضا هر ۱۰ ثانیه.
- خروجی ساب استاندارد Base64، Clash و sing-box.

## بررسی سرویس‌ها

```bash
sudo systemctl status vilo-xray vilo-node nginx --no-pager
```

```bash
sudo journalctl -u vilo-node -u vilo-xray -n 80 --no-pager
```

## تست محلی

```bash
python3 -I tests/node_agent_test.py
```

```bash
bash -n scripts/install_node.sh
```

تست‌ها از Xray و systemd شبیه‌سازی‌شده استفاده می‌کنند. نصب کامل روی VPS واقعی هنوز تأیید نشده است. متن و پرسش‌های نصب‌کننده انگلیسی هستند.

## محدودیت‌های فعلی

- اعمال تغییر فهرست کلاینت‌ها Xray را restart می‌کند؛ اتصال‌های جاری ممکن است لحظه‌ای قطع شوند.
- `userLimit` ذخیره می‌شود اما محدودیت تعداد دستگاه/IP همزمان هنوز اعمال نمی‌شود.
- وضعیت آنلاین از افزایش شمارنده ترافیک تخمین زده می‌شود، نه handshake واقعی؛ ISP شناسایی نمی‌شود.
- WS و ساب روی پورت 80 لایه TLS ندارند؛ لینک ساب را محرمانه نگه دارید؛ برای انتقال حساس از Reality استفاده کنید.
- نصب ناموفق ممکن است فایل‌های نیمه‌کاره باقی بگذارد؛ اجرای مجدد آن‌ها را خودکار حذف نمی‌کند. قبل از ترمیم بررسی و پشتیبان‌گیری لازم است.

## منابع اتصال

[مخزن PattNG](https://github.com/patterniha/PattNG) و [Patt’s Channel](https://t.me/patt_channel_x/166) منابع معرفی‌شده برای روش‌های اتصال هستند. طبق گزارش ارسالی ۲۰۲۶-۱۰-۲۱، ECH روی `cloudflare-ech.com` مسدود، F&F روی فایروال ایرانسل فعال و WARP MASQUE-HTTP/2 قابل اتصال گزارش شده است. این گزارش‌ها آزمون مستقیم این نصب‌کننده نیستند. MASQUE/Aether و F&F در این نسخه نصب‌کننده پیاده‌سازی نشده‌اند؛ تغییر fingerprint به‌تنهایی پیاده‌سازی F&F نیست.
